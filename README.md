# Business-Websites

Three independent website pitch concepts for local businesses in Indiranagar, Bengaluru.

- [Lubna's Designer Wear](https://somesh2566.github.io/Business-Websites/lubna/)
- [Kushal Decor](https://somesh2566.github.io/Business-Websites/kushal/)
- [Makeup by Savitha](https://somesh2566.github.io/Business-Websites/savitha/)
- [Collection](https://somesh2566.github.io/Business-Websites/)

Each subdirectory is a self-contained static website with original WebGL objects, scroll-driven storytelling, responsive layouts, and local enquiry drafts. No build step or runtime dependencies are required. Publish the main branch root through GitHub Pages.

These are independent concepts, not official business websites. AI-generated concept imagery is labelled and must not be presented as actual business portfolio work. Contact details and broad services come from public listings and need owner confirmation before an official launch. No enquiries are sent automatically; no appointments are reserved, payments collected, or analytics loaded.

Public-source references: [Lubna's listing](https://www.bharatibiz.com/en/lubnas-designer-wear-094493-48011), [Kushal Decor listing](https://www.bharatibiz.com/en/kushal-decor-080-2520-6677), [KC Fabrics locator](https://www.kcfabrics.com/NewStoresLocator.aspx), [Savitha listing](https://www.bharatibiz.com/en/makeup-by-savitha-099001-93989), [Savitha vendor profile](https://www.wedmegood.com/profile/Makeup-by-Savitha-1129693).

Generated image concepts: embroidered oxblood silk; a sage-curtain interior with terracotta seating; a fictional adult bridal portrait. Created using built-in Imagegen, then encoded to WebP. Original procedural 3D art is generated locally in each site's experience.js.

The noindex metadata asks search engines not to index these pitch demos; it is not access control.
